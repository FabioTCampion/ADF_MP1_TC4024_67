## Destaques

- Nova tela de gráficos para correlação, com três gráficos configuráveis de forma independente.
- Seleção livre de até oito variáveis por gráfico, organizada por categorias e com pesquisa.
- Filtros de variáveis compartilhados entre a tela de gráficos e a análise de quebras.
- Período, zoom e cursor sincronizados entre os três gráficos para facilitar comparações.
- Eixos separados automaticamente por unidade de medida.
- Layout dos gráficos salvo por usuário, com controle de revisão.
- Todas as páginas com filtro de período agora abrem em **Hoje**.

## Dados e compatibilidade

- O novo endpoint de tendências combina a telemetria otimizada com os históricos detalhados do processo.
- Variáveis booleanas são representadas como `0` e `1`.
- O banco existente é atualizado de forma aditiva, preservando dados, usuários e filtros já cadastrados.

## Validação

- Compilação de produção da interface concluída.
- 35 testes automatizados aprovados.
- Fluxos principais validados no navegador com dados reais do servidor.
